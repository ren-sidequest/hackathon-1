# EvidenceBridge HR

HR 端的独立开发目录，目前仅保留初始化入口，尚无应用代码、依赖或启动命令。

开发前阅读 [仓库规则](../../AGENTS.md)、[产品蓝图](../../docs/product/EvidenceBridge_PRODUCT_BLUEPRINT.md) 和 [UI 与交互基线](../../docs/product/EvidenceBridge_BASELINE.md)。技术栈与共享数据约定见 [项目计划](../../PROJECT_PLAN.md)。

负责岗位要求、初始证据报告、证据缺口、定向任务审阅与发送、候选人工作样本和过程证据审核，以及更新后的证据报告。遵循深色侧栏、浅色工作区和 HR 蓝色强调色。

从最新 main 建立独立分支后在本目录初始化。默认不修改 Candidate 端；涉及根目录构建配置、共享组件或跨端数据时先协调。初始化命令应保留本 README，不通过覆盖或删除整个目录清理占位文件。
